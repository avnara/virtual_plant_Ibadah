Kebijakan Privasi

Terakhir diperbarui: September 2026

1. Data yang Kami Kumpulkan

  • Data akun: ID Pengguna, nama tampilan, jenis kelamin, provinsi, kata sandi (tersimpan terenkripsi).
  • Data lokasi: koordinat GPS dan zona waktu, digunakan khusus untuk menghitung jadwal sholat yang akurat sesuai lokasi Anda.
  • Data aktivitas ibadah: jawaban misi harian (selesai/tidak), alasan tidak mengerjakan (termasuk opsi "haid" untuk pengguna perempuan), riwayat panen, dan pencapaian (achievement).

2. Cara Kami Menggunakan Data

  • Menghitung poin, tahap pertumbuhan tanaman, dan kesehatan tanaman.
  • Menampilkan jadwal sholat yang sesuai lokasi Anda.
  • Menyusun statistik pribadi (grafik mingguan/bulanan) yang hanya bisa Anda lihat sendiri.
  • Memicu pencapaian (achievement) berdasarkan pola aktivitas Anda.

3. Data Sensitif

Alasan "haid" hanya ditampilkan sebagai opsi untuk pengguna dengan data gender perempuan, dan disimpan sebagai bagian dari catatan aktivitas pribadi Anda. Data ini tidak ditampilkan ke pengguna lain dan tidak dibagikan ke pihak ketiga.

4. Penyimpanan & Keamanan

  • Data disimpan di server basis data terenkripsi.
  • Kata sandi disimpan dalam bentuk hash, tidak pernah dalam bentuk teks biasa.
  • Token sesi login (JWT) disimpan sementara di perangkat Anda (local storage browser) dan akan kedaluwarsa otomatis.

5. Berbagi Data

Kami tidak menjual atau membagikan data pribadi Anda ke pihak ketiga untuk tujuan komersial. Data lokasi hanya digunakan secara internal untuk perhitungan jadwal sholat.

6. Hak Anda

  • Anda dapat mengubah data profil kapan saja melalui menu Edit Profil.
  • Anda dapat meminta penghapusan akun beserta seluruh datanya dengan menghubungi kami.

7. Kontak

Pertanyaan seputar privasi dapat disampaikan melalui menu bantuan di dalam aplikasi.
